# Semana 03 - Laboratorio Fintech

Laboratorio enfocado en el manejo de datos sintéticos aplicados a un contexto de fintech.

## Contenido

- `lab_fintech_sintetico_2025_1000.py`: Script principal del laboratorio.
- `fintech_top_sintetico_2025_1000.csv`: Dataset sintético de transacciones o clientes.
- `fintech_top_sintetico_dictionary_1000.json`: Diccionario de datos para entender las variables del dataset.
