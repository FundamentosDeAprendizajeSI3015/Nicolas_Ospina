# Semana 10 - Pipeline de Clustering

Refactorización y creación de un pipeline robusto para tareas de clustering.

## Contenido

- `pipeline.py`: Implementación del flujo de trabajo (limpieza, transformación, modelado).
- `cluster.py`: Definición de los métodos de agrupación.
- `results/`: Salidas generadas por el pipeline.
