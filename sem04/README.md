# Semana 04 - Análisis Exploratorio de Datos (EDA)

Prácticas de exploración de datos y visualización para identificar patrones y anomalías.

## Contenido

- `EDA-NicolasOspina.py`: Script con el análisis exploratorio.
- `data/`: Datos fuente del análisis.
- `*.png`: Gráficos de dispersión, histogramas y matrices de correlación generados.
- `medidas_estadisticas.csv`: Resumen de métricas calculadas.
