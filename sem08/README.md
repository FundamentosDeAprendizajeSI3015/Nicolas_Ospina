# Semana 08 - Predicción FIRE UdeA

Análisis predictivo utilizando el dataset sintético FIRE de la UdeA.

## Contenido

- `prediccion_dataset_FIRE.py` / `prediccion_dataset_FIRE_realista.py`: Scripts de entrenamiento y predicción.
- `dataset_sintetico_FIRE_UdeA.csv`: Datos para el análisis.
- `reporte_metricas_FIRE_UdeA_realista.csv`: Métricas de desempeño del modelo.
- `results/`: Gráficos y visualizaciones de resultados.
